🔗 Links Principais
📋 Trello - Board Compras → 📊 Google Drive - Planilhas → 💬 WhatsApp Web →
✅ Pré-requisitos
  • Logado no Trello
  • Logado no Google Drive
  • WhatsApp Web ativo (escanear QR code se necessário)
  • Planilhas dos fornecedores no Drive
  • Etiqueta "fornecedores" no WhatsApp Business
📝 Como Usar
1Preparar

Abra as 3 abas: Trello, Drive, WhatsApp Web

2Listar

Clique em "Interface Completa" para ver fornecedores

3Loop Por Fornecedor

Para cada um: extrai dados → Bessani → atualiza Trello → WhatsApp

4Repetir

Continue até zerar a lista de fornecedores
