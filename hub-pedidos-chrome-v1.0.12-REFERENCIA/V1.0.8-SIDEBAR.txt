  Interface Principal: Sidebar (menos pesado, mais limpo)
═══════════════════════════════════════════════════════════════════════════════

🎯 MUDANÇAS PRINCIPAIS:

1. ✅ INTERFACE PRINCIPAL = SIDEBAR
   ❌ Antes: Popup pequeno + Sidebar auxiliar = confusão
   ✅ Agora: Sidebar grande com botão "INICIAR" em destaque

2. ✅ BOTÃO "🚀 INICIAR AUTOMAÇÃO" NA SIDEBAR
   - Fica visível e destacado no topo
   - Um clique e tudo começa
   - Menos cliques necessários

3. ✅ FILTRO AUTOMÁTICO POR "RIO CLARO"
   - Lista apenas fornecedores com etiqueta/nome "Rio Claro"
   - Ignora fornecedores de outras regiões
   - Mais direto, sem distrações

4. ✅ MENOS PESADO
   - Interface simplificada
   - Popup só mostra quando necessário
   - Sidebar fica aberta como painel permanente

═══════════════════════════════════════════════════════════════════════════════

📋 FLUXO NOVO (SEM MUDANÇAS DE USUÁRIO):

1. Clica na extensão
2. Sidebar abre grande (interface principal)
3. Lê: "Bem-vindo ao Hub de Pedidos"
4. Clica em "🚀 INICIAR AUTOMAÇÃO" (botão grande roxo)
5. Sistema:
   - Abre as 3 abas (WhatsApp, Trello, Google Drive)
   - Lista fornecedores "Rio Claro" automaticamente
   - Mostra progresso na sidebar
6. ⏸️ PAUSA: para cada etapa (Bessani, Trello, WhatsApp)
7. Você confirma/preenche dados
8. Loop até zerar lista

📊 MUDANÇAS DE CÓDIGO:

1. sidebar.html:
   - Adicionado botão "🚀 INICIAR AUTOMAÇÃO" no topo
   - Estilos CSS para destaque visual
   - Elemento #btn-iniciar-sidebar

2. sidebar.js:
   - Listener para clique do botão
   - Envia mensagem ao popup.js
   - Inicia automação via sidebar

3. popup.js:
   - Listener para receber comando da sidebar
   - chrome.runtime.onMessage para 'iniciar-automacao-sidebar'
   - Simula clique no botão de iniciar

4. content-trello.js:
   - Filtro por etiqueta "Rio Claro"
   - Extrai tags dos cards automaticamente
   - Retorna apenas fornecedores Rio Claro

5. manifest.json:
   - Versão: 1.0.7 → 1.0.8
